# koishi-plugin-curriculum-table

[![npm](https://img.shields.io/npm/v/koishi-plugin-curriculum-table?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-curriculum-table)

`koishi-plugin-curriculum-table` 是一个面向群聊场景的课程表管理插件。

插件在 Koishi 控制台注册独立侧边栏页面，可以管理多份课程表、编辑单元格、合并课程时间范围，并按目标群组定时汇总推送课程表图片。除定时推送外，也可以通过 `课表日程查询` 指令手动查询当前群组的课程安排。

## 功能特性

- 在 Koishi 控制台侧边栏管理多份课程表。
- 区分课表所属群组、用户以及推送机器人、推送目标群组。
- 支持克隆已有课表，保留课程内容和用户 ID，方便复用到其他群组。
- 课程表使用自适应宽度网格，支持上下、左右滚动。
- 支持单击选择单元格、纵向拖动选择、双击或长按操作。
- 支持 `Ctrl+C`、`Ctrl+V` 复制粘贴课程单元格和合并单元格。
- 重叠粘贴时会生成轻微错开的叠层，错开距离不会超过一行。
- 支持 `Ctrl+M` 合并单列中的连续单元格。
- 支持 `Ctrl+S` 保存当前课表。
- 支持 `Delete` 清空当前单元格。
- 右键菜单提供合并单元格、清空单元格等操作。
- 支持通过目标群组汇总该群下所有已配置用户的课表。
- 推送前通过机器人查询用户昵称并下载头像，头像会转为 Base64 后嵌入图片。
- 支持按星期设置推送，新建推送默认选择周一至周日。
- 支持推送前一天、当天或后一天课表。
- 支持隐藏已经结束的课程。
- 提供 `课表日程查询` 指令，用于手动查询当前群组课程安排。

## 依赖要求

插件需要的 Koishi 服务：

- 必需：`database`
- 必需：`console`
- 必需：`puppeteer`
- 可选：`glyph`

推荐使用 Koishi `4.18.0` 或更高版本，并启用 MySQL、SQLite 等数据库服务。

## 安装

可以在 Koishi 插件市场搜索：

```text
koishi-plugin-curriculum-table
```

也可以直接安装：

```bash
npm install koishi-plugin-curriculum-table
```

安装后在 Koishi 控制台启用插件。

## WebUI 编辑

启用插件后，控制台侧边栏会出现“课程表”入口，页面路径为：

```text
/curriculum-table
```

### 课表归属

每份课表包含两个核心归属字段：

- `课表所属群组 ID`：这份课表属于哪个群组。
- `课表所属用户 ID`：这份课表属于该群组中的哪个用户。

同一个用户 ID 可以出现在不同群组中，因此会分别保存为不同课程表。

推送设置中的字段与课表归属相互独立：

- `推送机器人`：实际执行发送的机器人。
- `推送目标群组 ID`：图片最终发送到的群组。

推送时会读取目标群组 ID 下全部用户课表并进行汇总。

### 编辑课程

课程表使用类似表格编辑器的单列选择方式：

- 单击单元格进行选择。
- 在单列中上下拖动可以扩展连续选区。
- 双击单元格后直接在右侧编辑。
- 右键或长按单元格打开操作菜单。
- 课程名称、开始时间、结束时间均在右侧编辑面板中设置。
- 未填写课程名称时，该单元格保持为空。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+C` | 复制当前选区中的课程单元格或合并单元格 |
| `Ctrl+V` | 粘贴课程；发生重叠时以轻微叠层显示 |
| `Ctrl+M` | 合并当前单列选区 |
| `Ctrl+S` | 保存当前课表及编辑内容 |
| `Delete` | 清空当前选区 |

复制粘贴使用页面内部剪贴板，不会影响浏览器或系统中的普通文本复制。

### 克隆课表

在左侧课表列表中右键课表，可以选择“克隆课表”。

克隆会复制：

- 课表名称
- 课表所属用户 ID
- 学期日期
- 全部课程和合并区域

修改克隆课表的“课表所属群组 ID”后保存，即可将同一个用户的课表复用到其他群组。

## 课表查询指令

### 课表日程查询

查询当前群组指定日期的课程表：

```text
课表日程查询
课表日程查询 昨天
课表日程查询 今天
课表日程查询 明天
课表日程查询 后天
课表日程查询 1
```

- 不填写日期时默认查询今天。
- 支持 `前天`、`昨天`、`今天`、`明天`、`后天`、`大后天` 等描述。
- 支持直接填写数字日期偏移。
- 查询结果以图片发送，并显示用户昵称和头像。

## 定时推送

推送设置在控制台的“课程表”页面中配置。

每条推送闹钟包含：

- 是否启用推送。
- 推送名称。
- 推送机器人。
- 推送目标群组 ID。
- 每日推送时间。
- 课表日期：前一天、当天或后一天。
- 触发星期。
- 是否在没有课程时也发送。

新建推送时默认启用，并默认选择周一至周日。

如果未选择任何触发星期，该推送不会发送。

推送内容固定为图片，并汇总目标群组下全部已配置用户的课表。

推送前插件会：

1. 使用对应机器人查询用户昵称。
2. 获取并下载用户头像。
3. 将头像转换为 Base64。
4. 将昵称和头像写入课程表图片。

如果用户头像无法获取，会使用带用户名称首字的备用头像。

## 插件配置

### screenshotQuality

图片压缩质量，范围 `0-100`，默认 `80`。

### footerText

图片页脚文字，默认：

```text
群友课程表
koishi-plugin-curriculum-table
```

直接使用换行即可，渲染时会转换为多行并居中显示，不需要填写 `<br>`。

### glyphFontFamily

glyph 字体服务的动态字体单选框。

默认字体为：

```text
方正像素12
```

未安装 glyph 或字体加载失败时，会回退到插件内置字体。

### enableDebugLogging

是否输出调试日志，默认关闭。

### hideFinishedCourses

是否隐藏已经结束的课程，默认开启。

开启后，推送当天或过去日期的课表时，结束时间早于当前时间的课程不会显示在图片中。

## 数据表

插件使用独立的 V2 数据表：

| 表名 | 用途 |
| --- | --- |
| `curriculum_schedule_v2` | 保存课表主体及群组、用户归属 |
| `curriculum_course_v2` | 保存课程单元格、时间范围和合并范围 |
| `curriculum_push_v2` | 保存推送机器人、目标群组、时间和触发星期 |

插件不会读取或修改旧版本课程表数据。
